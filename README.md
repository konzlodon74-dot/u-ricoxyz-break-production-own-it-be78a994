## How it works

`main.py` holds the single entry line as a constant, checks the bounty gate (1–200 characters, non-whitespace, exactly one line), then writes it to `/output/entry.txt` with no trailing newline. Python standard library only — no dependencies, nothing to install, just run `python3 main.py`.
